# Exploratory Replication of Kim et al. (2020)

## Overview

This repository contains an exploratory analysis inspired by the study **"Fecal Metabolomic Signatures in Colorectal Adenoma Patients Are Associated with Gut Microbiota and Early Events of Colorectal Cancer Pathogenesis"** by Kim et al. (2020).

The project was developed as a learning-focused replication to explore different analytical techniques using data from the study. It was originally created in the context of a hackathon to practice and showcase analysis workflows in a time-constrained setting. It is intended for educational and skill-building purposes only.

## Project Purpose

The aim of this work is to:

- Revisit a published colorectal cancer-related multi-omics study through an exploratory lens.
- Practice applying different computational and statistical methods to real biological data.
- Build familiarity with workflows for integrating metabolite data and microbial genus count data.
- Compare and test different analysis approaches in a non-clinical, non-diagnostic setting.

## Data Types

This project uses the following data types from the study:

- Metabolite data
- Genus count data

## Packages Used

The main R packages used in this analysis are:

- `mixOmics`
- `limma`
- `ANCOMBC`

## Scope

This repository is strictly exploratory. It does not aim to reproduce the original paper in a definitive way, establish new biological conclusions, or provide clinical interpretation.

The analysis was carried out to learn from an existing study design, experiment with methods, and better understand how different tools behave on this type of data, particularly within a hackathon-style project.
